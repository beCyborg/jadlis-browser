# jadlis-desktop

Мысль: часть работы лежит за твоим логином или в окне приложения на рабочем столе — плагины ведут уже открытый браузер и нативное окно, на каждом шаге берут самый дешёвый способ увидеть состояние и проверяют результат по факту.
