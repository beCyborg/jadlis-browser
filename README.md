# browser — залогиненный Chrome через Playwright MCP

Claude работает в **вашем живом Chrome**: все логины, куки, сессии и 2FA уже на месте. Никаких отдельных профилей, `--remote-debugging-port` и повторных авторизаций.

Плагин ставит два компонента:

- **MCP-сервер** `playwright` (`@playwright/mcp@0.0.78` в Extension Mode) с флагами токен-экономии: `--snapshot-mode=none --console-level=error --image-responses=omit`. Без этих флагов авто-снапшоты страниц накапливают до ~114K токенов на задачу; с ними та же задача укладывается в ~27K.
- **Скилл** `browser` — учит Claude лестнице чтения страницы (find → evaluate → scoped snapshot → полный снапшот → скриншот), правилам эффективности и границам безопасности.

## Установка

1. Установите плагин (см. [корневой README](../../README.md)).
2. Установите расширение [Playwright Extension](https://chromewebstore.google.com/detail/playwright-extension/mmlmfjhmonkocbjadbfplnigmagldckm) из Chrome Web Store (Chrome/Edge/Chromium).
3. Готово к первому запуску: при первом обращении Claude к браузеру расширение откроет страницу выбора вкладки и попросит подтвердить подключение.

### Токен (опционально, убирает диалог подтверждения)

Без токена каждое подключение MCP-сервера к браузеру нужно одобрять вручную. Чтобы подключение было автоматическим:

1. Кликните по иконке расширения Playwright Extension → откроется страница статуса.
2. Скопируйте значение `PLAYWRIGHT_MCP_EXTENSION_TOKEN`.
3. Claude Code спросит токен при включении плагина (поле «Playwright Extension Token»); сенситивное значение уезжает в Связку ключей macOS, в конфиг-файлы не пишется. Пропустили — задать позже можно через `/plugin` → browser → настройки.

## Проверка

В сессии Claude Code попросите: «покажи вкладки браузера» — Claude вызовет `browser_tabs(action: "list")` и вернёт список открытых вкладок.

## Если не подключается

Чек-лист из скилла (Claude пройдёт по нему сам, но можно и руками):

- Chrome запущен обычным способом (не headless, не отдельный профиль)?
- Расширение Playwright Extension установлено и включено?
- Не закрыта ли вкладка-мост, открытая расширением?
- Используется ли дефолтный профиль Chrome? Мост видит только профиль Default.
- Токен вводили? Проверьте, что он скопирован целиком со страницы статуса расширения.

## Безопасность

- Claude действует **под вашими логинами**. Скилл требует явного подтверждения перед необратимыми действиями (отправка, покупка, удаление) на залогиненных сервисах.
- `browser_run_code_unsafe` (произвольный JS в процессе сервера) скилл держит под гейтом: только доверенные страницы, по явной необходимости.
- Один линейный flow за раз: extension mode хрупок к параллельной работе с вкладками.
