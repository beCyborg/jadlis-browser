# Половина работы лежит за твоим логином, а агент видит ровно то, что открыто всем

`jadlis-browser` подключается к тому Chrome, в котором ты уже сидишь: логины, куки и 2FA
остаются на месте, второй профиль и `--remote-debugging-port` не нужны, а страницу скилл
читает по лестнице — от точечного поиска по дереву до полного снимка последним.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-browser@jadlis
```

Ключей не нужно, но нужно расширение-мост в самом Chrome: его ставишь ты, из Chrome Web Store.

![Браузер, в который ты уже вошёл, и забранные из него данные](docs/img/hero-jadlis-browser.webp)

Текстом: слева окно браузера с уже пройденными логинами, справа забранные со страницы данные,
внизу общее правило — брать самый дешёвый способ увидеть страницу, а не самый наглядный.

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Как это работает

![Задача за логином, мост к открытому браузеру, лестница чтения, действие с подтверждением, проверка](docs/img/how-jadlis-browser.webp)

На входе — задача на сайте, где ты уже вошёл; сам Chrome и вкладку держишь открытыми ты, не плагин.
Внутри — мост к расширению, лестница чтения от дешёвого к дорогому и вопрос перед необратимым.
На выходе — забранные данные и выполненные действия, проверенные по факту, а не по коду возврата.

Текстом: задача за логином → мост к открытому браузеру → лестница чтения → действие
с подтверждением → проверка результата по факту.

Ставит плагин две вещи: MCP-сервер `playwright` и скилл. Среда запуска зафиксирована в `.mcp.json`
репозитория: пин `@playwright/mcp@0.0.80` и четыре флага — `--extension`, `--snapshot-mode=none`,
`--console-level=error`, `--image-responses=omit`. Следствия видны сразу: после клика и навигации
агент «слеп», пока сам не позовёт чтение; base64 скриншота не приходит; включён только
core-набор инструментов.

Лестница чтения снизу вверх по цене: `browser_find` — grep по дереву доступности; `browser_evaluate`
— JS-функция, возвращающая только вычисленное значение; снимок поддерева по `target` и `depth`;
полный снимок — последнее средство для незнакомой структуры; скриншот — только там, где нужна
визуальная семантика, и всегда через `filename`.

Главная ловушка описана в скилле отдельно: полностью перекрытое окно Chrome macOS замораживает,
и клики, наведение и перетаскивание висят до таймаута, а `evaluate`, `find`, `type` и ожидания
продолжают работать. Лечится поднятием окна через `osascript` перед серией кликов.

Длинные сценарии от пяти шагов скилл отдаёт субагенту с жёстким контрактом ответа. Параллельных
браузерных субагентов нет: подключение в сессии одно, и все субагенты делят его.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин jadlis-browser из маркетплейса jadlis.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
2. claude plugin install jadlis-browser@jadlis
3. claude plugin list — покажи мне строку про jadlis-browser и его версию.
Потом скажи мне одной строкой: поставить в Chrome расширение Playwright MCP Bridge
из Chrome Web Store и перезапустить Claude Code.
Токен расширения необязателен, его спросит сам Claude Code при включении плагина.
Значение токена не печатай: проверяй только «есть» или «нет».
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй,
скажи, что именно пропустил, и иди дальше.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-browser@jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall jadlis-browser@jadlis --keep-data`.

**в) Короткая команда.** Открой Claude Code и набери:

```
/browser
```

Не находится — сверь имя строкой `claude plugin list`. Скилл поднимается и на обычной фразе:
«в моём браузере открой страницу заказов и вытащи статусы».

**Расширение в Chrome.** Поставь [Playwright Extension](https://chromewebstore.google.com/detail/playwright-extension/mmlmfjhmonkocbjadbfplnigmagldckm)
из Chrome Web Store (Chrome, Edge или Chromium), версия не ниже 0.3.0 — старый протокол мост
больше не понимает. При первом обращении к браузеру расширение откроет страницу выбора вкладки
и попросит подтвердить подключение. Токен со страницы статуса расширения этот диалог убирает:
Claude Code спросит его при включении плагина, значение уезжает в Связку ключей macOS и в конфиги
не пишется; пропустил — задашь позже через `/plugin` → jadlis-browser → настройки.

**Проверка.** «покажи вкладки браузера» → в ответе список открытых вкладок.

## Границы, стоимость, обновление

**Чего не делает.** Не заменяет обычный скрейпер: публичную страницу дешевле снять им, сюда идёт
то, что живёт за твоим логином. Не грузит файлы на сайт — в extension mode привилегированная
команда подстановки файла запрещена браузером, файл выбираешь руками или дропом. Не открывает
`file://`. Не работает в несколько потоков: одно подключение на сессию, параллельные браузерные
субагенты запрещены. Не блокирует необратимые действия технически — спрашивает, но клавиши от
твоего аккаунта у него твои. Произвольный JS в процессе сервера (`browser_run_code_unsafe`)
держится под гейтом: только доверенные страницы.

**Что нужно.** Ключей и подписок не нужно. Нужны Chrome (или Edge, или Chromium) с расширением
Playwright MCP Bridge не ниже 0.3.0 и `npx` в системе — им запускается сервер. Токен расширения
необязателен и только убирает диалог подтверждения. Приложению, из которого запущен Claude Code,
нужен Full Disk Access: без него сервер не может перечислить папку расширений Chrome и сообщает
«Extension not found», хотя расширение стоит.

**Порядок расхода токенов.** Прогон лёгкий: субагентов и фан-аутов нет, дорога здесь не модель,
а чтение страницы. Дороже прочего обходятся полный снимок незнакомой структуры и скриншоты,
поэтому оба стоят в самом низу лестницы.

**Проверено там, где я работаю:** мой Mac, мой Chrome. Связка `@playwright/mcp@0.0.80`
и расширение-мост прогнаны по тест-матрице `skills/browser/TESTS.md` 01.09.2026. Проверено только
на macOS; про другие системы сказать нечего.

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update jadlis-browser@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall jadlis-browser@jadlis --keep-data && claude plugin install jadlis-browser@jadlis
```
